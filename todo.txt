# Open items — feature requirements (full text: docs/requirements/README.md, status: docs/requirements/feature-status.md)

- [ ] Runbook editor in the UI (steps: owner, prerequisites, instructions, expected result, evidence, approval)   (§8)
- [ ] RACI matrix and recovery teams (role assignments with deputies are editable)                            (§10)
- [ ] Action items / findings & corrective actions UI (owner, deadline, status, retest)                         (§10, §15)

- [ ] Reports: scenario catalogue, BIA, exercise, incident, management summary, open findings; Excel export    (§18)
- [ ] ISO 22301 / ISO 27001 compliance mappings                                                                 (§17)
- [ ] Plan: recovery locations and failback as explicit sections                                               (§7)
